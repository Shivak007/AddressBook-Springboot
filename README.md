# Address Book App (Spring Boot)

## Project Overview
Spring Boot based Address Book Application implementing REST APIs with layered architecture and MySQL integration.

---

## Tech Stack
- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- MySQL
- Maven

---

## Features

### Section 1
- Basic REST APIs
- CRUD operations (GET, POST, PUT, DELETE)

### Section 2
- DTO & Model implementation
- Service Layer
- In-memory data storage

### Section 3
- Service Interface
- Repository Layer (JPA)
- MySQL Database integration
- Environment variables configuration

### Section 4
- Validation (`@NotBlank`, `@Pattern`)
- Global Exception Handling
- Custom Exception for invalid ID
